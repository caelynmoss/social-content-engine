# Peer creators: learn the craft, don't clone the author

Keep two clearly labeled collections: OWN posts (the selected author's actual writing) and PEER posts (public or user-supplied reference creators).

Only extract *abstract* craft patterns: use of cases, information density, argumentative pacing, clean diagrams, kinds of opening, question discipline, how conclusions earn their force. These may help select a drafting technique if compatible with OWN samples.

Never copy a living creator's signature wording, catchphrases, unusual metaphors, jokes, distinctive sequencing, life experiences, persona or stated opinion. Never pretend a peer endorsed the user or the user's employer. If someone asks for an exact named-writer clone, offer a high-level descriptor, e.g. "short decisive thesis and one concrete mechanism" rather than imitation.

A person's virality does not prove their argument is correct. Don't choose a trending post because of metrics alone. If a reference URL is inaccessible, label it unverified and work from supplied excerpts without claiming you read it live.
