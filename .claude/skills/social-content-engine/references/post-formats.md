# Writing formats: earn every sentence

The default is **one best draft**, not three paraphrases. Let the author's demonstrated habits determine length, emoji, hashtags, numbering and closing CTA.

## Short X post

- One focused argument within the platform's normal 280 **weighted** character limit (URL and some Unicode weighting matter). Use a reliable counter if exact length is promised; otherwise allow margin.
- Opening should convey a real observation, not "Everyone's talking about X" or "Here's why Y matters".
- Usually claim + mechanism/example + implication; omissions are fine when the author's voice is minimalist.
- Never overstate unknown facts to create a hook.

## Long single X post

- A coherent longer single post, usually 300–1200 characters or as requested, for an account **confirmed eligible to post longer text**. Otherwise split as a thread; don't mislabel an over-limit post as ordinary.
- Organize as progression not an essay outline. No forced headings or repetitive conclusion.

## Thread

- Default 4–8 distinct X posts, each within normal limit; use numbering only where consistent with the author.
- First post states a thesis or real tension. Middle posts must advance in different ways: premise, example, objection, implication, limitation. Final post resolves the argument or poses an authentic open question.
- If two posts say the same thing with different metaphors, merge or replace one. No gratuitous cliffhangers or follower bait.
- Keep sources outside publishable copy unless inline citations are requested.

## Rewrite and edits

- Never add new claims, fake experiences, unverified numbers or a stronger position without permission.
- When a user says "less AI", remove template-like contrast pairs, generic hype, hollow abstractions, overly symmetrical sentence lengths, excessive em dashes, forced rhetorical questions and polish that erases the writer's quirks.

## Output order

Deliver copy first for a drafting request. For THINK_WITH_ME, a concise reasoning sketch may come first because the *ideas*, not final prose, are the task. News citations and author-confidence notes follow outside the draft. If the user asks for "only the post", provide only the post.
