# Formats decided by each account's results

**First read the Account Profile's WINNING FORMAT line**. No platform-wide default to Short Post or Thread, no automatic 300-1200-character range for LONG_POST. If the user asks for a format, honor it where possible. If the profile is unknown, make a provisional decision based on intent and clearly indicate evidence is missing, without blocking writing.

Refer to `references/format-performance.md` for evidence. The Account Profile may prefer an X ARTICLE for in-depth original analysis while another creator wins with a short format. Format preferences are per account *and* content category.

## ARTICLE (a first-class output, not a long tweet)

Produce an editable article-length original composition: appropriate title, optional deck/lede, explicit central argument, well-developed sections, examples/data with dated sources where applicable, objections/limits and an earned conclusion. Shape and length follow the user's request, account's prior successful articles and the complexity of the topic. Do not impose an arbitrary word/character cap. Flag that native X Article publishing access or publishing workflow may vary by account; do not claim to publish it. If Article publishing is unavailable, offer a manual publishing alternative while keeping the requested Article draft intact. A long single post or thread is not the same as an Article.

## LONG_POST

A single longer X post in the account's observed successful length range, if eligible. There is no universal 300-1200 character target. If the user explicitly wants a single long post, draft it and flag any account or publishing limit rather than silently splitting it. Keep a coherent argument, natural paragraphs and precise sourcing.

## SHORT_POST

A single post within the platform's ordinary weighted character limit, with the author's actual point and no invented facts. Avoid generic hook formulas. If an account's historically successful 'short posts' exceed the ordinary limit due to premium features, classify them correctly by publishable surface and document the account-specific distinction.

## THREAD

Use when requested or supported by the account's results and narrative needs; do not assume 4-8 posts is the optimal number for everyone. Build true progression without filler. Ensure each post satisfies its applicable character limit; sources outside publishable text unless requested.

## REWRITE, QUOTE, CAPTION

Do not mirror content across accounts. A quote should add an independent reading or new context, not mechanically replicate the same news. Video/image captions are possible only with supplied/authorized assets; do not invent media. For existing copy, preserve actual stance and verified facts, then align expression, account positioning, account-approved vocabulary and red lines.

## Format decision order

1. Explicit author format request and access rights.
2. Account's measured winning formats and content category, including Article where supported.
3. Account positioning, audience needs and depth of actual argument.
4. Provisional format suggestion if empirical data is missing; make no claim about what 'wins'.

Return one best draft, not three versions by default. For official claims include source/approval status and references outside draft. For profile setup, put the format evidence first.
