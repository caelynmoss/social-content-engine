# X source access and safety

- **On-demand only.** The radar runs only upon an explicit user request, not in any recurring job or background monitor.
- **Live search first:** use legitimate current web/X search, then optional already-authorized official read-only X API, then genuine user-provided public X posts. No upfront API key requirement when search is available.
- **Official API:** https://docs.x.com/x-api/posts/search/introduction and https://docs.x.com/x-api/getting-started/pricing . Check credit costs and endpoint access. Respect 401/402/403/429 errors; no limit evasion.
- **X site rules:** https://help.x.com/en/rules-and-policies/x-automation . No passwords, browser cookies, unauthorized scripted site login/scraping, private Following timeline collection, auto-engagement or posting.
- **Truth and attribution:** Real X links and post timestamps are necessary for a CT discussion report. News websites are fact-checking context, not direct evidence of today's X discussion. No fabricated sources, activity counts or time claims.
- **Privacy:** Keep X tokens, personal voice cards, private reports and user-provided data out of the public GitHub repo. All writing is draft-only.
