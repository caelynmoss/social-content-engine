# Format selection by *this account's* evidence

**Question 0: Which format actually wins for this account?** Store the answer at the FIRST LINE of the Account Profile with evidence and confidence. A universal preference for Short Post or Thread is forbidden.

## Supported formats

- **ARTICLE:** a native X Article / comparable article-length document, if that account has publishing eligibility and the owner requests that target. Support title/subtitle, thesis, framing, reported evidence, nuanced analysis, sections and a real ending. Length is determined by the topic, account's successful article lengths, and user instruction -- no arbitrary 300-1200 character ceiling. Deliver a ready-to-edit article body and source notes, not a thread disguised as an Article.
- **LONG_POST:** a longer *single* X post if account can publish it. Don't prescribe a 300-1200 character range. Length distribution and user request determine target; respect account eligibility.
- **SHORT_POST:** one single regular X post within the ordinary character limit if the account's successful short-form posts suit it; allow explicit author request to override format choice.
- **THREAD:** multi-post sequence when sequential explanation, user request or demonstrated performance supports it; no automatic 4-8 ceiling for all accounts. Each post must satisfy platform limits.
- **OTHER:** e.g. image/video caption, quote, response, tutorial card when approved and the account's strategy supports it. Do not create unsupported media automatically.

**Article and long single post are different publishing surfaces.** If Article publishing permission is unclear, still prepare a named `ARTICLE DRAFT` when asked, while clearly noting the publishing eligibility/format check required. Do not silently substitute a thread.

## Performance evidence, not platform defaults

Build a private per-account dataset by format (e.g. own last 30-90 days or a user-supplied comparable window). Record each piece's date, account, category, original vs repost, format, observed impressions/views, engagement, saves, qualified follows/conversions when available. For a format summary show sample N, metric definitions, median (not only viral outliers), distribution, comparison window and confidence. Use **comparable** denominators; metrics like 100k views or 550 views are PERFORMANCE, never character limits.

Compare goals and normalized results where possible: views per follower, saves per thousand views, meaningful replies, qualified conversions, and the account's editorial purpose. Small, older or contaminated samples -> mark INCONCLUSIVE, propose a test, never invent a winner. A high view count can coexist with low conversion or poor fit. Accounts may prefer different formats for analysis vs announcements.

Priority order: 1) explicit request and publishing capability, 2) supported account performance & content category, 3) account strategy/positioning, 4) provisional judgment based on argument complexity. No universal default from this Skill. Provide a format recommendation briefly when it matters, not as an obstacle to drafting.

Source template: `assets/format-performance-template.md`. Review the winner periodically *when asked or when new data is supplied*, never autonomously run a calendar.
