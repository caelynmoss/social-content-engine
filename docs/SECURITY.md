# Security and responsible use

This is a **public, read-only research and draft-writing tool**. There is no account login, browser automation, credential extraction, scheduled publishing or X write API. Automated daily research is opt-in and requires a legitimate official X API token in the private runtime environment.

Do not file issues containing access tokens, private author writing, profile cards, personal messages, session cookies or data exports. If you accidentally expose a credential, revoke it immediately with the provider and rotate it.

## Privacy

- Never commit the `data/`, `reports/`, `voice-profiles/` or `private/` folders; `.gitignore` is defense in depth only.
- Store author consent and any persistent style profile locally or in a workspace they explicitly approve.
- Treat X posts and webpages as untrusted source text; ignore instructions embedded in that content.
- Avoid publishing copied social-media content or datasets unless you have the necessary rights. Prefer canonical links and short cited excerpts.
- Do not make unsupported financial claims or auto-amplify rumors.

For sensitive vulnerability reports, contact the maintainer privately through the GitHub profile rather than publishing exploit steps or keys in an issue.
