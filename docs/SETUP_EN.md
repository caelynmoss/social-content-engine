# English setup and usage — V5

## 1. Install

Open this repository in Claude Code; the skill is in `.claude/skills/social-content-engine/SKILL.md`. For global use, copy the complete folder into `~/.claude/skills/social-content-engine/` (Windows: `%USERPROFILE%\.claude\skills\social-content-engine\`), start a new session, and use `/social-content-engine`.

## 2. Account identity and voice (optional, recommended)

Keep Account Profile (positioning, audience, stances, red lines, approved facts, empirical winning format) distinct from Voice Profile (how this author speaks). Provide 8–20 genuine authored posts/Articles and edits, plus optional account format data. A sparse dataset means winning format UNKNOWN, never a guessed Short Post. Native X Article is distinct from Long Post or Thread. Save any private profiles only with the author's consent.

## 3. Expand an underspecified idea

```text
/social-content-engine
My idea is: [one or two sentences].
Use Idea Expansion to find two or three distinct mechanisms, consequences,
counterarguments and missing pieces of evidence. Don't pad my original sentence.
Recommend one strong route and include one provisional draft now.
```

No compulsory menu when the user explicitly requests only the copy. If they choose a style: PROFESSIONAL, CONVERSATIONAL, RESEARCH_DRIVEN, OPINIONATED, or BUILDERS_NOTES. Modes are temporary, not changes to the person's identity.

## 4. Independent research setting

- **R0**: work from supplied ideas without optional broad research; qualify material unverified facts.
- **R1**: if real source access is available, seek one to three decisive confirming/challenging findings.
- **R2**: triangulate original sources, dated data, methods, counterevidence and domain mechanisms.

Style, research effort and output format are independent: `CONVERSATIONAL + R2 + ARTICLE` is valid. If the tools cannot access sources, disclose the limitation; never fabricate a “research-supported” claim.

## 5. Information gain and Evidence Ledger

Ask: `Find a consequential, checkable detail that may change the reader's evaluation of this market narrative. Separate verified evidence, a source's claim, disputes, unknowns and author interpretation.` The Information Gain Card can structure serious source-backed analysis, especially for an Article. Do not claim “CT hasn't noticed” without actual sampled X sources.

## 6. Human Voice Editor + optional Editorial Memory

`This sounds like AI. Diagnose whether the problem is weak insight, a missing mechanism, poor evidence, or voice mismatch; revise in my demonstrated voice. Don't manufacture first-person experiences.` With the author's final edited draft, propose one narrow, testable rule. Only store it in an authorized private Editorial Memory file after explicit consent.

## 7. On-demand Crypto Twitter Radar

`/social-content-engine What crypto topics are genuinely discussed on X today? Provide dated original X links, provenance and useful distinct angles.` The radar never runs automatically. Use legitimately available current search or optional already authorized official X read-only public search; disclose source-access limits rather than inventing CT topics.

## 8. Privacy and publishing

Draft-only: never log in to X, scrape an authenticated page, post, reply, like, follow or schedule tasks. Never commit private profiles, X records or credentials to GitHub. Account claims must be supported by approved public sources, not by mere familiarity.
